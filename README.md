# C&M Backend

C&M은 개발자, 마케터, 영업 전문가를 연결해 스타트업 팀 구성을 돕는 매칭 플랫폼입니다. 이 저장소는 회원, 프로필, 팀, 펀딩, 메시지 기능을 처리하는 Spring Boot 백엔드 프로젝트입니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | C&M |
| 개발 형태 | 팀 프로젝트 |
| 서비스 분야 | 스페셜리스트 매칭, 스타트업 팀 빌딩, 펀딩 연계 플랫폼 |
| 주요 기능 | 회원, 마이페이지, 프로필, 팀, 펀딩, 메시지, 팔로우 |
| 상세 포트폴리오 | https://app.notion.com/p/3b2a62a7b8588178bf4ef883ba231864 |

## 기술 스택

- Java
- Spring Boot
- MyBatis
- MySQL
- Thymeleaf
- JavaScript
- HTML / CSS

## 서비스 흐름

1. 사용자가 회원가입과 로그인을 진행합니다.
2. 프로필과 경력/학력 정보를 등록합니다.
3. 파트너 목록에서 개발자, 마케터, 영업 전문가를 탐색합니다.
4. 팀을 등록하고 팀 상세 화면에서 구성원과 프로젝트 정보를 확인합니다.
5. 메시지와 팔로우를 통해 사용자 간 연결을 이어갑니다.
6. 팀 또는 프로젝트는 펀딩 등록과 결제 흐름으로 확장됩니다.

## 주요 기능

### 회원 / 마이페이지

- 사용자 기본 정보 관리
- 프로필, 경력, 학력, 활동 내역 표시
- 프로필 이미지 흐름 정리

### 파트너 탐색

- 직군 기반 스페셜리스트 탐색
- 파트너 카드 및 상세 정보 표시
- 팔로우/연결 기능과 연계

### 팀 등록 / 팀 상세

- 팀 기본 정보 입력
- 모집 조건과 카테고리 구성
- 팀 소개와 구성원 확인
- 팀 관리자 기능 분리

### 펀딩

- 펀딩 목록 조회
- 프로젝트 등록
- 결제 흐름 연계

### 메시지 / 팔로우

- 대화 목록 관리
- 메시지 송수신
- 팔로우 기반 사용자 연결

## 포트폴리오 관점의 정리 포인트

- 기능을 개별 화면 단위로만 보지 않고, 프로필 등록부터 팀 빌딩과 펀딩까지 이어지는 서비스 흐름으로 정리했습니다.
- 마이페이지와 팀 관련 기능을 통해 사용자의 정보 관리와 협업 연결 과정을 설명할 수 있도록 구성했습니다.
- 메시지와 팔로우 기능은 사용자 간 관계를 만드는 연결 기능으로 분류했습니다.
